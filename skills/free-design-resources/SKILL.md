# Free Design Resources

A curated lookup table of free, commercially-usable design tools and asset
sites, organized by task. Use this instead of guessing at URLs or searching
from scratch when a design task needs a specific kind of asset.

Source: [bradtraversy/design-resources-for-developers](https://github.com/bradtraversy/design-resources-for-developers)
(MIT License) — the upstream repo has hundreds more entries per category;
this skill keeps only the most broadly useful ones for client web/graphic
design work. For a deeper cut in one category, clone the upstream repo and
read its `readme.md` directly.

## When to Use

- Picking a color palette for a new client site or brand.
- Choosing a font pairing (heading + body) for a design.
- Needing icons, SVGs, or icon fonts for a UI.
- Needing illustrations, patterns, or background textures.
- Needing free stock photos (including food-specific for restaurant work).
- Presenting a finished design in a device/product mockup.
- Starting from an HTML/CSS template instead of a blank file.
- Needing a quick utility (favicon generator, gradient generator, image
  compressor, avatar generator).
- Looking for visual inspiration or a competitor's brand palette.

## How It Works

Each category below is a short table: tool name, what it's for, and the
link. Pick by task, not by browsing everything — go straight to the
category that matches what's needed.

### Color Palettes

| Tool | Best for |
|------|----------|
| [Coolors.co](https://coolors.co) | Fast palette generation (hit spacebar) |
| [Colormind.io](http://colormind.io) | AI-assisted palette generation |
| [Color Hunt](https://colorhunt.co/) | Browsing designer-made palette sets |
| [Adobe Color](https://color.adobe.com/create) | Harmony rules (complementary, triadic, etc.) |
| [whocanuse.com](https://whocanuse.com) | Contrast/accessibility check for a palette |
| [Brand Colors](http://brandcolors.net/) | Looking up a real brand's exact hex codes |

### Fonts

| Tool | Best for |
|------|----------|
| [Google Fonts](https://fonts.google.com/) | Default source — free, web-ready, huge library |
| [Fontjoy](https://fontjoy.com/) | Auto-generating a heading/body font pairing |
| [FontPair](https://fontpair.co/) | Pre-made Google Font pairing examples |
| [Font Squirrel](https://www.fontsquirrel.com/) | Vetted free-for-commercial-use fonts |
| [Fontshare](https://www.fontshare.com/) | Higher-end free fonts (Indian Type Foundry) |

Open-source alternatives to a system UI font (useful when a client wants
something distinctive but free): [Inter](https://rsms.me/inter/) (general
UI text), [IBM Plex](https://github.com/IBM/plex) (a full family — sans,
serif, and mono), [Manrope](https://manropefont.com/) (geometric sans),
[Space Grotesk](https://github.com/floriankarsten/space-grotesk)
(distinctive display sans).

## Examples

- "Preciso de uma paleta preto e dourado para um salão" → Color Palettes
  table → Coolors.co or Adobe Color, then check contrast with whocanuse.com.
- "Preciso de fotos de comida pro cardápio" → Stock Photos → FoodiesFeed.
- "Cliente quer ver o site num mockup de celular antes de aprovar" →
  Mockups → Smart Mockups or Device Shots.
- "Preciso de um ponto de partida em HTML pra não começar do zero" →
  HTML/CSS Templates → HTML5Up.
- "Preciso de ícones consistentes pro menu do site" → Icons → pick one
  library (don't mix styles) — Feather or Heroicons for a minimal look,
  Font Awesome for broadest coverage.

## Anti-Patterns

- **Mixing icon styles across a single design.** Pick one icon library per
  project — mixing Font Awesome with Feather (different stroke weights,
  different visual language) reads as inconsistent.
- **Skipping the contrast check.** A palette that looks good in a swatch
  can fail accessibility once applied to real text — always verify with
  whocanuse.com or a similar contrast tool before finalizing.
- **Using a mockup as the deliverable.** Mockups are for presenting a
  design to a client for approval, not a substitute for the actual
  responsive site.
