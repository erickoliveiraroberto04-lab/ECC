# Design Inspiration and AI Tools

A curated lookup table for visual inspiration, prebuilt UI components, and
AI-assisted design generation — organized by task so you can jump straight
to the right tool instead of browsing from scratch.

## When to Use

- Need to see real examples of a specific UI pattern (navbars, footers,
  hero sections, CTAs) before designing one from scratch.
- Need a full page/site design gallery for general inspiration or to show
  a client "here's the style direction."
- Want a prebuilt component library to speed up a build instead of coding
  every button/card/modal from zero.
- Want an AI tool to generate a first-draft image, logo, background, or
  full mockup instead of starting blank.
- Need a real company's public design system as a reference for how a
  professional team documents color/type/spacing decisions.
- Want a no-code or AI-assisted website builder for a fast client draft.
- Need a Figma plugin for a specific production task (contrast checking,
  mockup insertion, style guide generation).

## Examples

- "Preciso ver como outros sites fazem seção de depoimentos" → Inspiration
  & Galleries → search a curated gallery like Godly or Land-book for that
  specific section type.
- "Cliente quer um logo rápido pra aprovar o conceito" → AI Generative
  Tools → Logo Diffusion for a starting concept, then refine by hand —
  never deliver an AI logo unrefined as final work.
- "Preciso remover o fundo de fotos de produto do cardápio" → AI
  Generative Tools → Remove.bg.
- "Quero montar um protótipo clicável rápido pra aprovação do cliente
  antes de codificar" → No-Code / AI Website Builders → Framer or v0.
- "Preciso justificar pro cliente por que a paleta escolhida é acessível" →
  Figma Plugins → Contrast Grid or Stark, screenshot the pass result.

## Anti-Patterns

- **Shipping raw AI output as final client work.** AI generative tools
  (logos, images, full-page generators) are fast first drafts, not
  finished deliverables — always refine manually before handoff.
- **Copying a component library's visual style wholesale.** shadcn/ui and
  similar kits are extremely recognizable; restyle colors, radii, and
  spacing so a client's site doesn't look like every other shadcn site.
- **Treating a reference design system as a template to copy verbatim.**
  Material Design or Polaris are references for *how* to structure
  decisions (tokens, scales, rules) — not assets to lift directly into an
  unrelated brand.
