# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this Skill, please report it privately
before opening a public GitHub issue.

Please use GitHub's private vulnerability reporting feature:

**Security → Report a vulnerability**

When reporting an issue, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any relevant examples or proof of concept
- Suggested remediation, if available

Please do not publicly disclose the vulnerability until it has been reviewed.

## Scope

Security reports are especially relevant to issues that could:

- Cause an AI agent to execute unintended or unsafe instructions
- Lead to prompt injection or instruction hijacking
- Cause sensitive information to be exposed
- Result in unintended modification or deletion of files
- Cause an agent to perform actions outside the Skill's intended scope
- Introduce malicious or unsafe instructions into the Skill

Issues that are purely about SEO recommendations, accuracy of generated content,
or normal behavior of an AI model are generally not considered security
vulnerabilities.

## Response

We will review security reports and, where appropriate, take steps to reproduce,
investigate, and address confirmed vulnerabilities.

Please allow reasonable time for investigation before publicly disclosing a
security issue.
